🟢💾 HackMe Storage (HMS) — экономика v2 на hackme.tech · live API

Зафиксировали **прозрачные правила** третьей монеты полезного пула — **HMS** (полезный диск + полезный seal). Не «пустой SHA256»: клиенты платят **HMC** за encrypted B2B storage, майнеры получают **HMS** за доказанный объём и **manifest seal**.

✅ **Эмиссия (policy v2)**
• **0.5 HMS** base за каждую **sealed epoch** (прод: **1 час** → **~12 HMS/день** сети только с base)
• **+1%** от суммы **prepaid HMC** market-заказов в эпохе (спрос клиентов раздувает бюджет)
• Max supply: **21 000 000 HMS** · genesis float казны **105 000 HMS** (0.5%) — **уже on-chain**

✅ **Как делится эпоха**
• **35%** — storage (PoSt, quota × часы × tier)
• **65%** — seal (**75%** победитель nonce · **25%** participation по shares)
• **Нет seal → нет payout epoch** (честная связка диска и seal на уровне сети)

✅ **Тиры диска (storage weight)**
• HDD **1.0×** · SSD **1.15×** · NVMe **1.35×**
• **Combo +10%** — storage + seal на одном host_label

✅ **Что уже live на hub**
• `GET /api/hms/pool/stats` — KPI, `lane_economics`, **0.5 HMS/epoch**
• `GET /api/hms/market/pricing` · docs на сайте
• Dashboard: вкладка **HMS**, emission в ecosystem KPI

⏳ **Дальше (не скрываем)**
• **Heavy VPS #2** — Stratum для ASIC + крупные storage workers
• Mint выплат майнерам после эпох (`/api/hms/mint`) — ops/cron
• MiningPoolStats: строка HMS под HackMe Official Pool

Пример prepaid: **100 HMC** в эпохе → **+1.0 HMS** к бюджету (поверх 0.5 base).
