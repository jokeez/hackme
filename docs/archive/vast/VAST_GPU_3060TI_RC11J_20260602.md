## rc11j verdict (this host)

### PASS — mining on production pool (with libnvrtc12)

- **CUDA ~97–98 GH/s per GPU** (better than prior matrix OpenCL ~74 GH/s on same class host).
- Signed submits accepted; hits recorded on coordinator.
- Dual `-gpu0` / `-gpu1` workers visible in pool stats.

### WARN — pack / ops gaps found in field

1. **`pack_vast_gpu_matrix.sh --skip-build`** omits `minersign` / `fleetplan` → must upload or full pack.
2. **`env.vast`** from token-only pack lacks seed until `minersign -gen-seed` on host.
3. **`worker_autostart` fleet** failed without `HACKME_REPO_ROOT` + valid fleetplan JSON path on rent box.
4. **rc11j CUDA→OpenCL fallback** does **not** help when `libnvrtc.so.12` is missing at **link/load** time — need `detect_gpu_backend` → opencl binary, or pack script to `apt install libnvrtc12`, or build against `.so.13`.

### FAIL — OpenCL auto-fallback claim on “CUDA 13 only” hosts

On a stock Vast Ubuntu image with CUDA 13 but **no** `libnvrtc12`, `workerpoh-cuda` **cannot execute**. Runtime fallback in `DiscoverAccelerators()` is correct for NVRTC **runtime** errors, not missing `.so.12`.

**Workaround validated:** `apt-get install -y libnvrtc12` → full CUDA path works.
