[list]
[*][b]Multi-GPU → one rig row[/b] — Pool UI and [mono]/api/work/stats[/mono] now merge [mono]worker-gpu0[/mono] / [mono]worker-gpu1[/mono] under a single operator id (how real farms expect to see a box).
[*][b]Aggregated hashrate[/b] — Coordinator sums GH/s across merged GPU slots instead of showing a single-GPU slice.
[*][b]Vast-ready pack[/b] — Prebuilt [mono]workerpoh[/mono] + [mono]fleetplan[/mono]; no [mono]go[/mono] compiler required on rent hosts ([mono]SKIP_WORKER_BUILD=1[/mono]).
[*][b]Replay hygiene[/b] — Per-GPU nonce streams in fleet mode; documented abuse-clear workflow for test matrices.
[*][b]Graceful degradation[/b] — When cloud images ship CUDA 13 and NVRTC 12 binaries fail, [b]OpenCL mining continued[/b] with full submit/payout path on 4090, 5090, and 1080 Ti class hosts.
[/list]
