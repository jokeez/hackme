[b][color=#39FF14]Summary[/color][/b]

Integrators posting paid fuzzing work on hackme.tech no longer use a web console with admin tokens. We ship a small CLI and a [b]scoped developer token[/b] (orders only). The public website shows a [b]read-only[/b] status tracker.

[list]
[*][b]hackme-fuzzing[/b] — Windows [.exe] and Linux binary on [url=https://hackme.tech/downloads.html#fuzzing-client]official downloads[/url]
[*][b]No browser admin[/b] — do not paste production tokens into hackme.tech pages
[*][b]WASM built locally[/b] — remote [mono]/api/tasks/from_code[/mono] returns [color=#FF6060][b]403[/b][/color] on the public host (compiler stays off the internet edge)
[*][b]Fuzz API[/b] — not exposed on hackme.tech ([mono]403[/mono])
[*][color=#00D1FF][b]Miners unchanged[/b][/color] — HackMe OS ISO, Windows worker, HTTP coordinator pool (~GH/s fleet on hackme.tech)
[/list]

[code]
