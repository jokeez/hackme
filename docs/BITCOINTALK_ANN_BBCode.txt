[b]What is it?[/b]
HackMe is [b]open mining infrastructure[/b]: you run a desktop [b]node + pool worker[/b], connect to our [b]public coordinator[/b], submit verifiable work, and accrue [b]off-chain HMC[/b]. On-chain payouts arrive after [b]operator settlement[/b] — not automatically in every PoH block.

[b][color=#39ff14]Miner quick start[/color][/b]
[list=1]
[*] Download the [b]Windows[/b] or [b]Linux[/b] bundle from the official [url=https://hackme.tech/downloads.html]Downloads[/url] page.
[*] [b]Verify SHA256[/b] on that same page. Do not use random mirrors or Telegram “speed links”.
[*] [b]Windows:[/b] run [mono]start_hackme_public_pool.bat[/mono] from the zip.
[*] [b]Linux:[/b] set [mono]HACKME_PUBLIC_AUTHORITY_BASE=https://hackme.tech[/mono] and run [mono]scripts/ops/desktop_mode_up.sh[/mono] (see README in the repo).
[*] Configure [mono]WORKER_PAYOUT_MAP[/mono] so your worker id maps to your [mono]HMC-…[/mono] address (must match the operator map for settlement).
[*] Open [url=http://127.0.0.1:8080]http://127.0.0.1:8080[/url] → [b]Mining[/b] → [b]Start pool worker[/b].
[*] Track [b]Unpaid worker accrual[/b] on the dashboard and payout rows on the [url=https://hackme.tech/pool/explorer]explorer[/url].
[/list]
