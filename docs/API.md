# HTTP API

**English (integrators):** Default base URL is the server root (e.g. `http://127.0.0.1:8080`). When **`HACKME_ADMIN_TOKEN`** is set, mutating **POST** routes require `X-Hackme-Admin-Token` or `Authorization: Bearer …`. Main read paths: **`GET /`** dashboard, **`GET /api/status`** (chain, economics, `network_sync`, `miner_public_ux`), **`GET /api/metrics`** (node telemetry + mining/econ fields), **`GET /api/global/metrics`** (pool-wide KPIs), **`GET /api/worker/status`**, **`GET /api/worker/settlement`**, **`GET /api/wallet`**, **`GET /api/wallet/earnings`**, **`GET /api/chain`**, **`GET /api/reports/blocks`**. Pool worker: **`POST /api/worker/start`** / **`POST /api/worker/stop`** (admin). Genesis: **`POST /api/genesis`**. Orders: **`POST /api/tasks`**, **`POST /api/tasks/from_code`**. Full tables and Russian prose below are kept in sync with the implementation.

Базовый префикс: корень сервера (по умолчанию `http://127.0.0.1:8080`). Все JSON-ответы с `Content-Type: application/json` где указано.

## Аутентификация мутаций (опционально)

Если задана переменная окружения **`HACKME_ADMIN_TOKEN`** (непустая строка), перечисленные ниже **POST** без секрета получают **401 Unauthorized** и заголовок **`WWW-Authenticate: Bearer realm="hackme-admin"`**.

Передайте токен одним из способов:

- **`X-Hackme-Admin-Token: <token>`**
- **`Authorization: Bearer <token>`**

Если переменная **не** задана, mutating POST маршруты не требуют admin-заголовок. Рекомендуется держать `HACKME_REQUIRE_ADMIN_TOKEN=1` и не открывать bind-адрес публично без токена. Модель угроз и чеклист на сеть — **`docs/SECURITY.md`**.

## Заказы (SQLite `tasks`)

| Метод | Путь | Описание |
|--------|------|----------|
| POST | `/api/tasks` | Загрузить манифест заказа (JSON в теле). **401** при активном `HACKME_ADMIN_TOKEN` без секрета; **429** при burst/rate-limit. Поля: **`id`** (уникальный), **`kind`**: `synthetic_poh_v1`, **`reward_hmc`** &gt; 0, опционально **`difficulty_score`** (1..100, дефолт 1), опционально **`target_solves`** (по умолчанию 1, максимум 10000), опционально **`ttl_sec`** (ручной TTL; если не задан — вычисляется автоматически), опционально **`payer_ref`** (идентификатор заказчика, до 256 рун). Fairness-guard: **`reward_hmc >= difficulty_score × 0.0005`**. WASM-gate: либо **`wasm_check_hex`** (hex модуля), либо **`wasm_artifact_path`** (относительный путь к `.wasm` под **`tasks/artifacts/`** или **`HACKME_TASK_ARTIFACT_DIR`**) **и** **`artifact_hash`** (SHA-256 файла, 64 hex); не оба сразу. С кошелька узла списывается: **`prepaid_hmc = reward_hmc × target_solves`** + **`order_fee_hmc = prepaid_hmc × 0.05`**; действует hourly cap `HACKME_MAX_ORDER_ESCROW_PER_HOUR_HMC` (по prepaid части). Успех **200**: `{ "ok", "id", "payer_ref", "prepaid_hmc", "order_fee_hmc", "total_debit_hmc", "order_burn_hmc", "balance_after", "expires_at", "ttl_sec", "signature_ed25519", "signing_public_key_ed25519", "verified_by", "verification_receipt" }` — подпись считается по **точным байтам тела запроса**. `verification_receipt` содержит `pool_id`, `request_sha256`, `issued_at_unix` и подпись пула по receipt-payload. **400** — ошибка валидации; **402** (`Payment Required`) — недостаточно HMC на кошельке. |
| POST | `/api/tasks/from_code` | Создать заказ из исходного кода (admin-only). Тело: `{ "id"?, "language": "<lang>", "code", "reward_hmc", "difficulty_score", "target_solves", "payer_ref"? }`. Языки: **`rust`**, **`c`**, **`cpp`**, **`tinygo`**, **`zig`**, **`assemblyscript`**, **`wat`**. Алиасы: `rs→rust`, `gcc→c`, `c++/cxx/cc→cpp`, `go/golang→tinygo`, `as→assemblyscript`, `asm/assembly/wast/wasm-text→wat`. На узле должны быть в **`PATH`** процесса ноды: `rustc` (часто rustup), **`clang`** (c/cpp), **`tinygo`**, **`zig`** (zig), **`asc`** (AssemblyScript, обычно `npm i -g assemblyscript`), **`wat2wasm`**. Компиляция по возможности под **bwrap/nsjail**; без них — **host compile (lab-only)**. Прод: **`HACKME_FROM_CODE_REQUIRE_SANDBOX=1`** (fail-closed без sandbox helper). Для **tinygo**, **zig** и **assemblyscript** после компиляции выполняется sanitize (остаётся только экспорт функции **`check`**, удаляется start-секция), затем тот же strict ABI-gate (`check(i64)->i32`, ровно один function-export). Ошибки: `compile_failed`, `wasm_validation_failed`, `wasm_sanitize_failed`, `manifest_rejected`. На VPS см. `scripts/ops/install_vps_from_code_toolchains.sh`. |
| GET | `/api/tasks` | Список заказов: `{ "tasks": [ { "id", "artifact_hash", "reward", "difficulty_score", "status", "created_at", "kind", "target_solves", "progress_count", "progress_pct", "payer_ref", "prepaid_hmc", "expires_at", "cancelled_at", "cancel_reason", "refunded_hmc" } ] }`. Статусы: `open`, `completed`, `cancelled`. При авто-истечении TTL открытый заказ переводится в `cancelled` с `cancel_reason="timeout"` и возвратом неиспользованного escrow в кошелёк (`refunded_hmc`); уже выплаченные solve-награды майнерам не откатываются. При наличии открытого заказа с `reward_hmc > 0` майнер берёт его **раньше** синтетики и `./tasks/*.json` (FIFO по `created_at`). Прогресс увеличивается при PoH-блоках с `order_task_id` в payload задачи блока |

| Метод | Путь | Описание |

| GET | `/api/p2p/peers` | Снимок известных пиров и health-статус. Ответ `{ enabled, peers[] }`, где для каждого peer есть `peer_url`, `node_id`, `height`, `tip_hash`, `seen_at`, `healthy`, `last_attempt_unix`, `last_ok_unix`, `next_retry_unix`, `last_latency_ms`, `consecutive_failures`, `flap_count`, `last_state_change_unix`, `unstable`, `quality_score`, `quality`, `last_error`. |

## Коды ошибок

- **401** — задан `HACKME_ADMIN_TOKEN`, но запрос не содержит корректного секрета (см. раздел «Аутентификация мутаций»).
- **409** — повторная инициализация генезиса.
- **412** — майнинг без генезиса (`Precondition Failed`).
- **402** — `POST /api/tasks`: недостаточно баланса для эскроу заказа.
- **405** — неверный HTTP-метод.
- **400** — невалидная transfer-транзакция; поле `code` содержит причину (`invalid_signature`, `invalid_nonce`, `insufficient_balance`, и т.д.).
- **400** — невалидная transfer-транзакция; поле `code` содержит причину (`invalid_signature`, `invalid_nonce`, `insufficient_balance`, `pending_nonce_conflict`, и т.д.).
- **429** — сработал локальный rate-limit (`/api/tx/send`, `/api/tasks`, `/api/p2p/tx`, `/api/push_work`) или anti-abuse лимит coordinator.
