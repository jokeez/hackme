Utility — why the token exists

Mining

Pool work that finds vulnerabilities in real code settles to on-chain HMC.

Security scans

Customers escrow HMC for Dig/Hunt campaigns — demand beyond speculation.

Network fees

Transfers and order creation debit HMC; burn tally reduces long-term supply pressure.

Allocation & vesting

~99.95% of max supply enters via miner/order emission. No declared team pre-mine beyond public genesis treasury.
