Chain rewards, coordinator payouts, and orders

HackMe is not classic pooled PoW where every share maps to a block fraction. Three layers: on-chain PoH, coordinator accounting, and paid audit orders. Companion coins (SUP, HMS) use separate rules — see ecosystem registry.

Block header vs wallet credit

  • PoH rewards credit the node primary wallet so GET /api/wallet stays consistent.
  • The block still records miner_address for transparency.
  • Pool GPUs do not automatically split each chain block unless coordinator settlement implements it.

Public pool payout (fair mode)

accrual ≈ (attempts / 1,000,000) × reward_per_m + found_bonus
reward_per_m ≈ base_reward × 1,000,000 / target_mod
  • Set WORKER_PAYOUT_MAP before expecting settlement.
  • Dashboard accrual is the paycheck story; on-chain balance updates after settlement.
  • Hybrid Ed25519 signing + per-worker caps keep the pool fair.
  • SUP accrual runs in parallel (quality-gated) — see SUP page.
