Privacy Policy

How HackMe processes telemetry and operational data to keep network infrastructure stable and secure.

Version 1.2 Effective date: 2026-07-16 Reviewed: 2026-07-17

1. Data categories

Service logs, node diagnostics, API request metadata, security events, and optional support communication records.

2. Processing purposes

Reliability, abuse prevention, incident response, performance tuning, release quality checks, and legal compliance.

3. Retention model

Operational logs are retained only for required troubleshooting and security windows, then rotated/deleted.

4. Public pool telemetry

Unauthenticated pool APIs may show worker IDs, hashrate, and accruals for transparency. Miner client IP addresses are not published on public /api/work/stats or /api/work/by-wallet responses (admin-only details remain private).

5. Data sharing

Data is shared only with required infrastructure providers or legal authorities where mandated by law.

6. User rights

Users may request access, correction, or deletion where legally applicable, subject to security and compliance constraints.

7. Policy updates

Material policy changes are posted with revision date; continued usage indicates acceptance of updated policy.
