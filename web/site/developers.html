Windows integrator path

  1. Install node from Downloads — start dashboard at 127.0.0.1:8080.
  2. Top up Wallet → on-chain HMC on #wallet (starter spendable = 0). Dig/Hunt Start auto-funds prepaid escrow.
  3. Download both hackme-fuzzing and hackme-fuzzing-build into the same folder.
  4. Use the developer token from install, or issue one on the local dashboard / hackme-fuzzing register --base http://127.0.0.1:8080 --save.
  5. Recommended: hackme-fuzzing wizard --pack secrets --package audit — or --wasm guard.wasm.
  6. Open report_url / gate_url on http://127.0.0.1:8080 · wire gate into CI.

Create orders on localhost — not on the public hub.
