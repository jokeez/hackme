Fuzzing orders on your local node

Buy useful GPU work on the HackMe network: security gates, synthetic PoH audits, WASM-validated tasks. Run hackme-node on your PC — 127.0.0.1:8080/#wallet and #orders — pool on hackme.tech fills the work.

Integrator API token (automatic)

Issue a scoped X-Hackme-Developer-Token on your local node (dashboard header → Issue, or CLI below). Tokens issued here on hackme.tech are for API testing only — create orders on localhost, not in the browser on this site.

Who this is for

  • Security vendors posting audit workloads
  • Studios needing WASM gate verification
  • Integrators building on HMC escrow
  • Not for GPU miners — use Downloads

What you get

  • Local dashboard — 127.0.0.1:8080/#orders, WASM upload, wallet escrow
  • hackme-fuzzing CLI — automation (token in env file, not admin)
  • Public tracker — read-only wallet + redacted orders
  • Coordinator switches to orders mode when work is open
  • Full spec in DEVELOPERS_FUZZING.md

Quick start (curl)

# Wallet (public)
curl -sS https://hackme.tech/api/wallet | jq '{address,balance_hmc}'

# Integrator CLI (token from support@hackme.tech — never paste in a web page)
export HACKME_DEVELOPER_TOKEN='…'
hackme-fuzzing wallet
hackme-fuzzing create manifest.json
hackme-fuzzing tasks

# Auto token (no support ticket)
hackme-fuzzing register --save
hackme-fuzzing build -lang rust -source check.rs -out ./fuzzing-out
hackme-fuzzing create ./fuzzing-out/my-order.manifest.json

# Remote from_code returns HTTP 403 on hackme.tech (build WASM locally).

When your order is open, pool workers receive the WASM gate in /api/work/claim and can commit order blocks — escrow pays the solver's miner_address, not a separate bounty for "finding a CVE". Small coordinator accrual may still apply for attempts. See economics model.
