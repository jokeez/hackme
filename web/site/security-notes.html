Security operations baseline

  • Keep HACKME_ADMIN_TOKEN enabled in all non-dev environments.
  • Pool coordinator: set HACKME_COORDINATOR_ADMIN_TOKEN before exposing HACKME_COORDINATOR_ADDR beyond loopback; optional fail-closed startup with HACKME_COORDINATOR_REQUIRE_ADMIN_TOKEN=1.
  • Restrict sensitive ports to trusted IPs and internal loopback.
  • Treat 429, invalid nonce/signature spikes, and stale peers as alertable events.
  • Re-run security and release readiness scripts before each public upgrade.
