The rules, in full

  • Three repositories per person.
  • The repository must be public and carry a clear licence.
  • The campaign has to actually run. A placed-but-never-started campaign cannot be ranked.
  • We rank the target and the run. A detector counter does not win — a thin target that trips many detectors loses to real work on code that matters.
  • This is not a CVE promise. Fuzzing finds what it finds; a clean run is still a real result.

The honest fine print

  • We read every registration by hand. That is also how we keep the promo from being abused.
