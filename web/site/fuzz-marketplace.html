How a job gets on this board

  1. 1Pick a targetA library or parser that reads untrusted input is where fuzzing pays.
  2. 2Order the campaignOn Orders, priced per run. Unused budget returns to your balance.
  3. 3The pool runs itYour job appears above and the counters move as machines pick up work.
  4. 4You get the reportEvery crash with an input that reproduces it, plus the corpus that was grown.

A clean run is a real result too — it tells you the target held up against everything the network threw at it, and you keep the corpus either way.
