B2B · Local node (recommended)

Orders & wallet on your PC — not on hackme.tech

Run hackme-node (same stack as mining rigs). Open http://127.0.0.1:8080/ → Wallet (your HMC in local DB) → Market (create order, upload WASM). Pool on VPS picks up work; you see hash rate like a miner. No web portal, no operator treasury on the site.

  1. Download node binary or HackMe OS below (or build from GitHub).
  2. Start node — dashboard at 127.0.0.1:8080.
  3. Header → Developer token → Issue (or hackme-fuzzing register --base http://127.0.0.1:8080 --save).
  4. #orders — Security audit tab, or faster: hackme-fuzzing wizard --wasm guard.wasm --package audit from CLI.
  5. Watch pool stats / Workers tab while miners complete the job.

SHA256SUMS (ISO)

ISO button uses GitHub Releases (same bytes as CDN). Verify SHA256SUMS-iso.txt before flash.

3 steps

  1. Download ISO + verify SHA256SUMS-iso.txt.
  2. Flash to USB 8 GB+ — whole disk, not a partition (see below).
  3. Boot → read recovery phrase on TTY1 → mining starts.

Flash correctly: Balena Etcher or sudo dd if=HackMe-OS-….iso of=/dev/sdX bs=4M conv=fsync status=progress (replace sdX with the USB disk, not sdX1). In Rufus choose DD image mode. Avoid Ventoy/multi-partition USB unless you know casper — wrong flash causes overlay … no support found and GPT warnings.

Commands on rig: hackme-os-status · hackme-show-wallet · hackme-os-install /dev/sda (persist to disk).

Boot: HackMe OS (live · recommended) or USB fix · load to RAM if overlay/GPT errors. Login: ubuntu (empty password) or sudo -i. If overlay … no support found: use newest ISO from this page (SHA256 in SHA256SUMS-iso.txt), re-flash whole USB disk with Etcher/dd (not Rufus ISO mode).

Windows

Installer: per-user setup (no admin UAC), pool token included, worker watchdog keeps mining alive.

Download HackMe Setup (.exe) Portable ZIP (if Setup does not open)

Buttons use GitHub Releases (same SHA256 as site CDN). If a browser download looks short, re-fetch and verify SHA256SUMS.txt.

NVIDIA on Windows: OpenCL worker (~9 GH/s). HackMe OS / Linux: native CUDA (~60+ GH/s). Upgrading? Run repair_fair_env.bat in the install folder to refresh hackme.env.

Setup does nothing? Use Portable ZIP → extract → setup_hackme_miner.bat → start_hackme_miner.bat. Or right-click Setup → Run as administrator. Windows may block downloads — click Unblock in file Properties.

Download verification

Operator checklist before production.

  1. Match version with the news announcement on News.
  2. Validate SHA256 locally (sha256sum -c SHA256SUMS*.txt).
  3. Compare sizes with RELEASE_MANIFEST.json.
  4. Never run binaries from unofficial mirrors or Telegram DMs.
