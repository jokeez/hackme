Download verification

Quick operator checklist before running binaries in production.

  1. Match filename, version, and platform with release announcement.
  2. Validate SHA256 from SHA256SUMS.txt locally.
  3. Review RELEASE_MANIFEST.json for hash and size parity.
  4. Store bundle and checksum evidence in your rollout log.

Open source

Build and audit the same code that runs the public pool. Official repository: github.com/jokeez/hackme (Apache-2.0). Production binaries on this page must match SHA256SUMS — do not trust unofficial mirrors.

Installation flow

  1. Download your platform bundle and checksum file.
  2. Verify hash locally.
  3. Install using bundled script/installer.
  4. Configure node, coordinator URL, and tokens.
  5. Run post-install health checks and sync verification.
