Billing & security

  • No public treasury wallet. Escrow is managed by the network operator. You do not top up an address shown on this site.
  • Use a unique payer_ref and order id to track your jobs. Commercial prepayment: contacts.
  • WASM only: upload a compiled .wasm check module — not raw source. Source stays on your machine unless you choose to share it with the operator separately.
  • Server validates WASM size, ABI (check(i64)→i32), and sandbox rules before accepting an order.
  • Developer token in sessionStorage (this tab only). Prefer CLI ~/.config/hackme/developer.token for automation.
