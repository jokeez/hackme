Architecture

Separation of duties keeps consensus data on the node while pool telemetry and leased nonce ranges flow through the coordinator.

Operator-facing numbers: use GET /api/global/metrics for the same chain height, difficulty, and pool hashrate every miner should see. Treat GET /api/metrics as local hardware and session telemetry — its hashrate_th_s field is not the pool aggregate.

Canonical node

Chain source of truth, wallet and tasks API, PoH mining when enabled, and strict WASM verification for orders.

Coordinator

Worker claim/submit lifecycle, payout accounting, aggregate stats surfaced to dashboards.

Workers

Fleet clients in controlled worker mode; coordinate ranges instead of competing forks against canon followers.

Explorer

Read-only projection for blocks, transfers, and address balances — isolate from mutating APIs.

Proof of Analysis (utility layer)

HackMe pays for measurable compute: audit orders decompose into deterministic segments for fuzz, property, and symbolic-style workloads. Rewards tie to accepted segments and verified artefacts rather than blind noise.

  • Coordinator leases bounded nonce batches per worker session.
  • Accepted submissions advance campaign evidence and telemetry streams.
  • Deliverables include coverage deltas, crash/finding feeds, and signed report bundles.

Orders from code · WASM languages

On a local node, operators compile gate modules via POST /api/tasks/from_code when toolchains are installed (dashboard Orders tab). Each pipeline emits a hashed WASM artifact with export check(i64) → i32. Remote from_code on hackme.tech is blocked — build WASM locally or use POST /api/security-audit on your node.

Rust C C++ TinyGo Zig AssemblyScript WAT

Aliases (e.g. gcc→c, go→tinygo, as→assemblyscript) are normalized server-side — see API reference.

Economics model (chain · pool · orders)

HackMe separates on-chain PoH rewards (credited to the block-producing node's primary wallet), coordinator worker accounting (accrual and settlement policy), and paid audit orders (escrow and fee splits). This is not the same as classic pooled PoW where every share automatically maps to a fraction of each block subsidy.

Desktop install path

For miners/operators who prefer app-style UX, use Desktop Mode wrappers on top of the same node/coordinator APIs.

  • Linux launcher install: bash scripts/ops/install_linux_desktop_launcher.sh.
  • Desktop lifecycle: desktop_mode_up.sh, desktop_mode_status.sh, desktop_mode_stop.sh.
  • First run generates admin token when missing and enables local desktop profile flags.
  • Dashboard includes a first-run wizard for token generation plus Solo/Worker start buttons.

Security layers

  • Distinct admin vs P2P credentials.
  • Rate limits and malformed payload rejection.
  • WASM sandbox validation before orders go live.
  • Artifact hashes plus hardened storage paths.

Economics controls

  • Fairness rails tying reward to difficulty.
  • Escrow, burns, and ledger-visible debits.
  • TTL cancellation with automated refunds.
  • Canonical KPI feeds for operator dashboards.
