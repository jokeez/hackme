Three steps

  1. Install — Win/Linux node from Downloads. Open http://127.0.0.1:8080 → Wallet.
  2. Order — fund HMC, then hackme-fuzzing wizard --pack filter_utf8 --package audit (packs: secrets · script_bounds · filter_utf8 · parser_expat · or --wasm guard.wasm · dashboard #orders).
  3. Deliverable — wizard prints report_url, gate_url, pulse_url. Pool diggers pick customer work first.

Why not a shop on hackme.tech?

Orders spend your HMC from a local wallet. Putting checkout on the hub would make the site a custodian — wrong for security customers and for the multi-coin roadmap. Same pattern later for HMS and other lanes: site = catalog + onboarding, node = shop + settlement.
