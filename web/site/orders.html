Security orders

Fuzz your C/C++ code before attackers do.

Fuzzing feeds your parser or library millions of malformed inputs and watches for memory bugs. You get a crash report with an input that reproduces it, a CI gate for your pipeline, and an honest CLEAN when nothing turns up. Priced in HMC; the unused part of your budget comes back.

What you get

Found

Crash report + reproducer

Crash class (heap overflow, use-after-free, …), the stack, and the exact input that triggers it, so your developers can fix it the same day.

CI

A gate for your pipeline

A pass/fail URL your CI can check. Run the same scan on every release and fail the build when a crash comes back.

Honest

CLEAN is not "secure"

If nothing crashes, the report says CLEAN and shows how much was tested. It is evidence, not a guarantee, and we never sell it as one.

How to order

  1. Install the node from Downloads and pick the Orders role (Windows setup or Linux). It opens a local dashboard on your machine.
  2. Add HMC to the wallet in that dashboard.
  3. Start a scan: choose a package and your target, press Start. The budget is locked in escrow and the report link appears when it finishes.

Today, a scan you start from your own node runs on your own machine. Running on the public pool (the 6–16 h and ~1 day times above) is set up with us for now: contact us with the target and package, and we open the escrow on the network so pool miners pick it up. Self-service pool orders come back once that path is reworked.

Questions

Does my code leave my machine?

For scans on your own node, no. For pool runs, the compiled test harness (not your source tree) runs on miners' machines inside a sandbox. Do not order pool runs for code you cannot share in compiled form; use a local scan instead.

What if a crash is found?

The report and the crashing input are private: they open only with your report token. The miner who found it gets a bounty share from your escrow. Pool runs show the campaign title on the public campaign board, so pick a neutral title if the target is confidential. Public disclosure of the bug is your call.

Why is there no checkout on hackme.tech?

Your HMC stays in your own wallet until you start a scan; the site never holds your funds. hackme.tech is the catalog and the docs.

Which languages and targets?

C and C++ libraries and parsers with a libFuzzer-style entry point work best. Quick scans also take a WASM guard. If you are unsure, ask us first.

For developers: CLI, packages and API

The hackme-fuzzing CLI ships next to the node in the Orders profile. Example:

hackme-fuzzing wizard \
  --wasm ./guard.wasm \
  --package audit \
  --title "Acme script bounds"

Guard packs: secrets · script_bounds · filter_utf8 · parser_expat · bounds_smoke · overflow_smoke · state_smoke. The wizard prints report_url, gate_url and pulse_url.
