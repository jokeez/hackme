Three steps

  1. Install — from Downloads: Windows Setup → Orders, or Linux bash start_hackme_orders.sh (tar/deb). Opens http://127.0.0.1:8080/#orders · sync token on #wallet (starter HMC = 0).
  2. Order — top up on-chain HMC on #wallet, then Dig/Hunt Start (auto-funds escrow) or CLI ./hackme-fuzzing wizard --pack filter_utf8 --package audit (CLI ships next to the node in Orders profile; packs: secrets · script_bounds · filter_utf8 · parser_expat · bounds_smoke · overflow_smoke · state_smoke · or --wasm guard.wasm · dashboard #orders · Hunt inventory).

Why not a shop on hackme.tech?

Orders spend your on-chain HMC from #wallet; Start locks prepaid escrow in one click. Putting checkout on the hub would make the site a custodian — wrong for security customers and for the multi-coin roadmap. Same pattern later for HMS and other lanes: site = catalog + onboarding, node = shop + settlement.
