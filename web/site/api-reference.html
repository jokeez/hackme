HackMe Network

API Reference

HackMe HTTP API for nodes, miners, and operators

Clean entry point for integration: canonical metrics, mining control, tasks/orders, fuzz campaigns, transfer flow, and pool coordinator endpoints.

Base URL: node root JSON contracts Admin token for mutating POST

Core endpoints

Fast-start subset used by UI, scripts, and integrations.

Method Path Purpose
GET /api/global/metrics Canonical global KPI source for all miners (chain/network/work aggregate).
GET /api/metrics Local node telemetry (hardware, economics, mining). Field hashrate_th_s is a synthetic idle baseline — pool-wide TH/s is only on /api/global/metrics (network.global_hashrate_th_s).
GET /api/status Node chain state and policy exposure for operator checks.
POST /api/mining/start Start PoH mining (requires genesis; admin token if enabled).
GET /api/wallet Redacted billing notice on hackme.tech; full wallet on local node (admin).
POST /api/tasks Create order/task with escrow, validation gates, and TTL logic.
GET /api/fuzz/campaigns List fuzz/property/symbolic campaigns. Mutating routes require admin token; reports accept X-Hackme-Report-Token.
GET /api/fuzz/campaigns/{id}/gate CI/release gate: pass/fail + reasons against severity thresholds.
GET /proof/{id} · …/badge.svg Proof of Fuzz public facts + README badge when public_proof is set (else token/admin). No finding payloads.
POST /api/security-audit B2B wizard path: WASM/pack campaign + escrow. Config may include input_mode, guard_pack, public_proof.
POST /api/tx/send Submit signed transfer transaction (v1).

Fuzz lifecycle primer: fuzz-guide.html. Full route tables: docs/API.md (Fuzz Campaigns).

Authentication

For mutating routes use X-Hackme-Admin-Token or Authorization: Bearer ....

Without valid token: 401 Unauthorized.

Coordinator flow

Worker mode uses claim/submit pair: /api/work/claim and /api/work/submit.

Stats endpoint /api/work/stats supports compact and detailed responses.

Error model

Use HTTP + JSON code fields for machine handling: 400/401/402/409/412/429.

Rate-limit and anti-abuse are expected behavior under burst load.

Fuzzing / B2B

B2B: hackme-fuzzing wizard on 127.0.0.1:8080 · packages · public tracker.
