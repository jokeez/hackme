Get started in minutes

Public pool worker flow (recommended for most miners).

  1. Download the node and verify SHA256 on the release manifest.
  2. Open the dashboard → genesis once → Start worker on Mining (or use Desktop Mode wizard).
  3. Payout accrues on the coordinator; on-chain balance follows settlement on the canonical chain.

Set HACKME_POOL_COORDINATOR_URL to the public coordinator base — details in Docs. Fleet rewards use coordinator accrual, not per-GPU block splits. Economics →
