HackMe is installed.
===================

What was configured:
  • hackme.env with pool token (from pool.miner.token)
  • Local admin token for the dashboard
  • GPU backend per your wizard choice
  • Start menu + optional desktop shortcut

Start mining:
  • Open "HackMe Miner" from the Start menu or desktop
  • Keep that window open — a background watchdog restarts the pool worker if GPU stops
  • Browser: http://127.0.0.1:8080/#ecosystem

Linux rigs: use HackMe OS live ISO from https://hackme.tech/downloads.html#hackme-os
  (Zero-Knowledge Start — no wallet setup; write down the recovery phrase on screen)

Install folder (default):
  C:\Program Files\HackMe

If mining does not start:
  • Start menu → HackMe → Configure miner
  • Or reinstall from https://hackme.tech/downloads.html

Support: https://hackme.tech
